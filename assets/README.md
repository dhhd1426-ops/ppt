# 手帐素材库

手帐 app 用到的、以及以后可能用到的全部素材。文件名开头的英文表示适合的动效：

- `grow`：从底边长出来
- `hang`：从顶边垂下来
- `float`：飘进画面
- `corner`：从角上伸进来
- `strip`：横向远景条
- `bg`、`paper`：底纹、纸张
- `scene`、`painting`：成组的场景或整幅画

| 文件夹 | 内容 | 来源 |
|---|---|---|
| `lishiqingzhao/original/` | 李清照 PPT 里的全部原图（43 张） | Release `ppt` 里的 `default.pptx` |
| `lishiqingzhao/layers/` | 从 PPT 第 2 页抠出来的图层（PPT 里是图片填充的形状，原图里没有） | 同上 |
| `flower-world/` | 树影婆娑（FLOWER WORLD）的 15 幅油画插画 | Release `ppt` 里的 `PPT.pptx` |
| `camellia/` | Camellia 模板的全部原图和一段音乐 | Release `ppt` 里的 `039.ppt.pptx` |
| `gpt/` | 用 GPT 新画的元素 | 用户提供 |
| `app/` | app 里实际在用的压缩版（webp），和 app 图标 | 由上面这些处理而来 |

新做的素材请按 `素材制作规范` 出图：PNG、真透明背景、长边 1600 到 2048 像素，再放进 `gpt/`（或者新建一个按来源命名的文件夹）。
